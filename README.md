# static-assets

Static image assets for documentation and presentations.

## Contents

This repository hosts agentic workflow diagrams in PNG format. Each workflow is available in full resolution and a resized variant for embedding in docs or slides.

| Asset | Description |
| --- | --- |
| `Agentic Workflow diagram - Autonomous delivery.png` | Full-size diagram for autonomous delivery workflows |
| `Agentic Workflow diagram - Autonomous delivery resized.png` | Resized variant of the autonomous delivery diagram |
| `Agentic Workflow diagram - Self healing incidents.png` | Full-size diagram for self-healing incident workflows |
| `Agentic Workflow diagram - Self healing incidents resized.png` | Resized variant of the self-healing incidents diagram |

## Usage

Reference images directly from this repository (for example via raw GitHub URLs) or copy the files into your project as needed. Prefer the `resized` variants when file size or layout constraints matter; use the full-size versions for print or high-detail views.

## Contributing

Add new assets with descriptive filenames. When a smaller embed-friendly version is useful, include a companion `resized` image alongside the full-size file.
